## ✦ Who is Malfurra?

**Muhammad Yasin** — known across the web as **Malfurra** and **its_sinn01** — is a software developer, open-source package maintainer, and **SIJA (Sistem Informasi, Jaringan, dan Aplikasi)** student at **SMKN 2 Yogyakarta**. Passionate about bridging low-overhead backend automation, cloud-native infrastructure, and local AI engineering.

Currently focused on:

﹒Maintaining high-performance **WhatsApp WebSocket libraries** (`@phrolovaa/baileys` & `@noya4u_27/baileys`)
﹒Developing automated store & digital commerce workflows (`noya-bot`)
﹒Simulating **Linux network topologies, Private Clouds, & SRE architectures** (`nftables`, BIND9, HAProxy, Proxmox VE, AWS)
﹒Building **Local LLM & RAG pipelines** with Python, Ollama, and ChromaDB
﹒Crafting **interactive 3D WebGL/Three.js web apps** and **native Android apps** in Kotlin
